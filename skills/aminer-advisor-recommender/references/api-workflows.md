# AMiner API workflows

Base URL: `https://datacenter.aminer.cn/gateway/open_platform`.

Send `Authorization: ${AMINER_API_KEY}` and `X-Platform: openclaw`. For POST requests, also send `Content-Type: application/json;charset=utf-8`.

## Candidate discovery

1. Resolve the university's first-level ID with free `org_search`. For combined university/department strings, call `org_disambiguate_pro` (¥0.05) and take `一级ID`/`一级`, not `二级ID`; if it fails, resolve the explicitly extracted university name separately. If free search returns a translated or fuzzy name without an exact name/alias match, confirm the ID with `org_disambiguate_pro` before use.
2. Use `person_search` (free) when a scholar name or institution is known.
3. For a named university and direction, first use `paper_qa_search` (¥0.05) with `org_id: [first-level ID]`, `use_topic: true`, and `query: "direction term"`. Do not add `org_terms`: the two institution filters combine by OR, so the result would no longer be school-ID restricted. Search up to three direction/alias terms separately. If the ID-filtered pass is empty, use `paper_search_pro` (¥0.01) with `org` and `query`. Inspect a bounded, round-robin paper sample across aliases; only if no candidate survives identity checks use one bounded global `query` pass and check affiliations afterward. For institution discovery without a known school, use global `paper_search_pro` for seed schools, then `discover --schools` for first-level org-ID comparison under the same queries and recent-year window. The explicit-school pass mixes `force_year_sort` and `force_citation_sort` results under the same `org_id` and `query`; the latter recovered CogVLM and InternVL when the newest slice missed them. The citation list can place pure language-model papers ahead of direct multimodal work, so direct title matches receive first chance within the bounded sample. Check authors' affiliation text in `paper_detail`, and treat title/keyword matches as stronger direction evidence than an incidental abstract match. For multimodal LLM discovery, exclude papers matching only a generic “multimodal” alias without evidence of a language or foundation model. Citation buckets and inspected counts describe a bounded portfolio; neither is a national rank.
4. `paper_info` author entries contain names only; `paper_detail` supplies author `org` and `orgid`, but neither endpoint supplies a person ID.
5. Constrain paper authors by the target university `orgid` or explicit university text in their affiliation (paper authors often have department-level `orgid`). Then accept only exact-name profiles at the university in `person_search`. Keep multiple matches unresolved instead of merging or guessing. A requested department remains unverified until its official faculty page confirms it.
6. Use `discover` when no institution is known: aggregate organization IDs from direction-matched paper details as a seed sample. For a school comparison, include plausible schools that this seed missed, then query each selected first-level org ID with up to six identical direction terms, paper limit and five-year window. Inspect at most 16 papers per school sampled across terms. Count only papers whose detailed author affiliation text names that school; AMiner occasionally returns an `orgid` that conflicts with the author organization text, and those conflicts are counted separately rather than credited. Return zero or unresolved schools visibly; label the result a bounded comparison, not a global ranking.

## Evidence enrichment

- Use free result fields first.
- `person_detail` (¥1.00) is available through `--verify-roles N` for per-school role checks or directly via `scripts/aminer_client.py --api person_detail --params '{"id":"PERSON_ID"}'` for a final cross-school shortlist. The shared `call_aminer_api` wrapper, when present, instead takes `person_id` and maps it to the HTTP `id` parameter; the same distinction applies to `person_paper_relation`. Do not rerun broad school discovery to verify positions; current department and actual supervisor eligibility still need official sources.
- `person_figure` (¥0.50) is opt-in for structured career evidence. `person_paper_relation` (¥1.50) supplements a named-person search when fewer than five recent focus papers survive identity and direction checks.
- Use `paper_info` (free) to normalize a small batch of known paper IDs.

## Institution expansion

`organization_person_relation` (¥0.50) is reserved in the client but not enabled by this workflow.

## Named scholar and focus

For a named scholar, use `person_search` to establish the exact full name and university first; its fuzzy search can return a different longer name. With a specified research focus, search recent papers by `author` plus the **extracted first-level university name** in `org` using `paper_search_pro`'s `query` field (title and keyword coverage); a profile's full institute/department/university affiliation can make the API return empty. Include English title-language aliases where appropriate. The primary term is searched in both `order: year` and documented `order: n_citation` within the same five-year window; the bounded sample is then shared across aliases so a full first page cannot suppress other subtopics. The controlled `code` case retrieved Zhang Ming's MARCO paper with `query`, while `keyword` missed it in two repeated calls. Retrieve `paper_detail` for the bounded result set and include a paper only when a same-name author has the selected university's organization ID or explicit university affiliation. Judge direction fit from the title and author keywords; incidental abstract wording is too weak to make an unrelated watermarking paper a code-generation result. If fewer than five recent focus papers survive, request `person_paper_relation` with the HTTP parameter `id` set to the selected person ID, filter its returned `author_id` to that ID, prioritize matching titles across the full relation before the 200-ID cap, and verify actual years and title focus with batched `paper_info`. Merge distinct results and return relevant papers first; label other ID-linked recent works `topic_match: false` so they are context, not proof of the requested focus. For a broad portrait or comparison, opt into `--broad-context`: one citation-ranked and one newest-year no-query `paper_search_pro` pass per scholar stay in the same five-year window. Each checks at most 20 papers with `paper_detail`. The former returns up to six representative papers in `broad_context_papers`; the latter returns up to ten emerging works in `recent_context_papers`, both separate from the focused set. An off-focus context paper is not direct evidence of the requested subfield. The relation can recover works signed at an earlier institution, but does not verify the original author affiliation or final publication status; label that provenance and check primary sources for important claims. If no university profile matches the user's explicit school, return disambiguation instead of selecting a high-citation namesake elsewhere. Verify current appointment, department, and research direction with official pages before optional collaboration analysis.

## Collaboration analysis

No dedicated collaboration endpoint is assumed. Derive collaboration evidence from verified paper authors and affiliations returned by paper endpoints. Count distinct academic and industry organizations in the inspected paper sample. If affiliation fields are absent, mark collaboration breadth as unavailable rather than inferring it. Country metadata is not verified, so do not claim international collaboration.

An official university-hosted scholar or laboratory page that explicitly identifies a named company joint laboratory or research project is a second, different form of industry-collaboration evidence. Record its URL and wording; do not merge it into paper-derived coauthor counts. For an external-university requirement, require a coauthor affiliated with another university or an explicit official inter-university project. A hospital or institute within the target university is not an external university. The mere presence of a company in a scholar's employment history or of a university in a broad consortium is only a lead until the relationship to this candidate is clear.

`paper_info` returns author names but not author organization IDs. Use it for free candidate discovery. Use `paper_detail` (¥0.01 per inspected paper) to obtain author `org` and `orgid`, then batch `org_detail` (¥0.01 per call) to verify organization type when available. Exclude the candidate's own organization by ID, not by translated name alone.

The collaboration script mixes recent and citation-ordered school papers in a five-year window; broad AI queries still omit many older or less-cited joint papers. For a verified scholar with no company evidence in the bounded result, a targeted `paper_search_pro` query with `author` set to the exact English name and `org` set to one plausible enterprise can locate leads. Omit `query` and `keyword` on this first pass so a generic topic token cannot suppress an otherwise valid collaboration. Verify the target author, school affiliation, and company coauthor together in `paper_detail`; the search hit alone is insufficient and a same-name author may be different. Use several distinct paper IDs before claiming collaboration **breadth**.

## Cost guardrails

Default to at most 10 candidates. The CLI computes a per-school worst-case estimate before any API request. At or above `--max-cost` (default ¥5.00), show the estimate and stop; pass `--yes` only after explicit confirmation. API errors surface structurally and failed calls are excluded from the successful-call cost ledger.
